# APTG-RL Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans. Steps use checkbox syntax.

**Goal:** Implement the one-day slice of APTG-RL, run pre-registered experiments, and ship paper (LaTeX PDF), repo COLDER, video, and form text.

**Architecture:** Python package `aptg` simulates a 3-agent repeated discrete-price game with scripted collusion mechanisms and prompt perturbations; detectors (baselines + prompt-conditioned directional graph) score episodes; a PPO investigator decides when to alert. Haiku subagents supply a small LLM-agent dataset via round-synchronous batch files.

**Tech Stack:** Python 3.13, numpy, scipy, scikit-learn, networkx, gymnasium, stable-baselines3, matplotlib, pytest; Tectonic (LaTeX); ffmpeg; gh.

**Spec:** `docs/superpowers/specs/2026-10-25-llm-pricing-collusion-design.md` (plus the two APTG_RL PDFs).

## Global Constraints
- 3 agents, discrete actions in {0,1,2,3,4} (price levels), coalition = agents {0,1}, outsider = agent 2. Scripted episode length T=40, LLM T=12.
- ~100 episode seeds per key scripted condition; seeds fixed in config; splits by seed, prompt family, mechanism; never split windows of one episode.
- Conditions C0-C6 exactly as proposal Sec. 3.2. Primary metrics: AUROC, AUPRC, TPR@FPR=0.05, detection delay, observation cost.
- Episode-level bootstrap (1000 resamples) 95% CIs; BH correction across ordered pairs; block permutation null (block=5, 200 perms).
- `PREREG.md` committed before any confirmatory run. All paper numbers come from `results/numbers.json` via script. No invented data or references.
- Report negative results; apply proposal Sec. 14.1 decision rules. No Claude attribution in commits (user rule).

## Review Focus
- Episode with constant actions (zero variance): estimators return 0, never crash or score collusion.
- Fewer than minimum samples per edge: edge marked uncalibrated, excluded from alerts.
- Test set with no positives: metrics return NaN with a warning, not an error.
- Unseen prompt family at test time: flagged out-of-calibration, not extrapolated.
- LLM subagent returns invalid or missing action: fall back to previous action, count and report the rate.
